# NZXT-ESC - أفضل تكامل ويب لأجهزة NZXT

### محرر تخطيط تخصيص الشاشة المتقدم لأجهزة NZXT Kraken AIO

أنشئ تصاميم شاشة LCD لأجهزة NZXT Kraken قابلة للتعديل بالكامل، باستخدام عناصر تراكب سحب وإفلات للمستشعرات، وخطوط مخصصة، وصور، وGIF، وAPNG، وفيديوهات MP4 وWebM، وساعات، ورسوم بيانية، وبيانات التشغيل الحالي، ورسومات متجاوبة مع الصوت، مع معاينة النتائج مباشرة عبر **NZXT CAM Web Integration**.

## تخصيص شاشة NZXT Kraken LCD دون تخطيطات ثابتة

يحوّل NZXT-ESC شاشة NZXT Kraken إلى مساحة تصميم حرة الشكل. أنشئ شاشة LCD مخصصة عبر وضع كل مستشعر أو رسم بياني أو ساعة أو صورة أو عنصر وسائط بالضبط حيث تريد. غيّر حجم العناصر، ودوّرها، وأعد ترتيبها، وأعد تسميتها، واقفلها، وصمّمها، مع مشاهدة النتيجة تتحدث مباشرة عبر NZXT CAM.

لا يتطلب المحرر الأساسي **حسابًا** ولا **تثبيتًا منفصلًا لدى المستخدم**. تبقى الإعدادات المسبقة والوسائط المحلية في تخزين المتصفح. تستخدم عناصر التراكب الموسيقية الاختيارية تطبيق [NowPlaying.WebSocket](https://github.com/mrgogo7/NowPlaying.WebSocket) المحلي لنظام Windows.

## البدء السريع

### الفتح مباشرة داخل NZXT CAM

[![Open NZXT-ESC in NZXT CAM](https://img.shields.io/badge/Open%20NZXT--ESC%20in-NZXT%20CAM-8b5cf6?style=for-the-badge)](https://cam-redirect.nzxt.com/action/load-web-integration?url=https://nzxt-esc.pages.dev/)

1. انقر على **Open NZXT-ESC in NZXT CAM**.
2. اسمح لمتصفحك بفتح NZXT CAM.
3. أكّد **Load Web Integration**.
4. افتح بطاقة Web Integration الجديدة واختر **Configure**.
5. أنشئ تخطيطك؛ تُزامَن التغييرات مع شاشة Kraken.

<details>
<summary><strong>الإعداد اليدوي داخل NZXT CAM</strong></summary>

1. افتح **NZXT CAM**.
2. انتقل إلى **Lighting → Kraken → LCD Display**.
3. اختر **Web Integration**.
4. افتح إعدادات **Custom Web Integration**.
5. أدخل:

   ```text
   https://nzxt-esc.pages.dev/
   ```

6. اختر **Apply** ثم **Add as Card**.
7. افتح البطاقة الجديدة واختر **Configure**.

## المزايا

| الإمكانية | ماذا تمنحك |
|---|---|
| **محرر تخطيط حر الشكل** | اسحب كل عنصر وغيّر حجمه ودوّره وبدّل طبقاته واقفله وأعد تسميته وحدد موضعه بدقة. |
| **بيانات مستشعرات NZXT CAM الحية** | أنشئ عروضًا مخصصة للمعالج وكرت الشاشة والذاكرة وحرارة السائل والطاقة والتردد وسرعة المروحة. |
| **رسوم بيانية متقدمة** | ادمج رسومًا بيانية شعاعية وخطية ودائرية وتاريخية للمستشعرات في تخطيط واحد. |
| **خلفيات متحركة** | استخدم الألوان والتدرجات والصور المحلية وملفات GIF وفيديوهات MP4 وروابط الوسائط المباشرة ومصادر YouTube وPinterest. |
| **تكامل التشغيل الحالي** | اعرض غلاف الألبوم ومعلومات المقطع ورسومات متجاوبة مع الصوت من عميل Windows محلي. |
| **استكشاف والمكتبة** | استورد إعدادات مسبقة من المجتمع، وعدّل كل جزء فيها، ونظّم المفضلة، واحتفظ بمجموعتك الخاصة من الإعدادات المسبقة المحلية. |
| **تخزين محلي أولًا** | تستخدم الإعدادات المسبقة LocalStorage؛ وتُخزَّن الوسائط المحلية في IndexedDB وتبقى على جهازك. |
| **محرر متعدد اللغات** | استخدم الواجهة بـ 20 لغة مدعومة. |

يستخدم كل عنصر نفس أسلوب العمل المرئي حيثما أمكن: حدده في المعاينة أو في قائمة الطبقات، ثم اضبط موضعه وحجمه ودورانه وترتيبه ونمطه وإعداداته الخاصة بنوعه.

### مراقبة العتاد

أنشئ تخطيطات حية باستخدام بيانات مراقبة NZXT CAM المتاحة، بما في ذلك:

`حرارة المعالج` · `حمل المعالج` · `تردد المعالج` · `طاقة المعالج` · `سرعة مروحة المعالج` · `حرارة معالج الرسومات` · `حمل معالج الرسومات` · `تردد معالج الرسومات` · `طاقة معالج الرسومات` · `سرعة مروحة معالج الرسومات` · `استخدام الذاكرة` · `حرارة السائل`

يمكن للأنظمة متعددة معالجات الرسومات اختيار المعالج النشط تلقائيًا أو استخدام معالج رسومات محدد. كما يوفّر محرر المتصفح قيمًا تجريبية عند تعذّر الوصول إلى واجهة برمجة NZXT CAM، ما يتيح تصميم التخطيطات ومعاينتها رغم ذلك.

### الخلفيات والوسائط

استخدم لونًا صلبًا أو تدرجًا كأساس، ثم أضف وسائط من:

- ملفات PNG أو JPG أو GIF أو WebP أو MP4 محلية
- روابط صور وفيديوهات مباشرة
- فيديوهات YouTube
- روابط وسائط Pinterest

يمكن تحديد موضع وسائط الخلفية وتحجيمها وملاءمتها ودمجها مع أي تخطيط تراكب. تُخزَّن الملفات المحلية في IndexedDB ولا يرفعها NZXT-ESC إلى أي مكان.

### الإعدادات المسبقة، استكشاف، والمكتبة

- احفظ ونظّم حتى **20 إعدادًا مسبقًا مخصصًا** في المكتبة المحلية.
- أنشئ كل إعداد مسبق بحد أقصى **40 عنصر تراكب**.
- استورد وصدّر ملفات الإعدادات المسبقة القابلة للتعديل للنسخ الاحتياطي أو المشاركة.
- تصفّح التخطيطات التي أنشأها المجتمع عبر **استكشاف**.
- أضف إعدادًا مسبقًا من استكشاف إلى المكتبة، وخصّصه، واجعله خاصًا بك.
- حافظ على تزامن التعديل وعرض Kraken بين عرضَي NZXT CAM.

## التشغيل الحالي والمصور الصوتي

يعمل عميل [NowPlaying.WebSocket](https://github.com/mrgogo7/NowPlaying.WebSocket) الاختياري لنظام Windows محليًا، ويرسل بيانات جلسة الوسائط وطيف الصوت إلى NZXT-ESC عبر اتصال WebSocket محلي.

استخدمه لإضافة:

- **غلاف الألبوم** الغلاف الحالي مع عناصر تحكم في الحجم والإطار والزوايا
- **نص التشغيل الحالي** العنوان أو الفنان أو الألبوم مع تمرير النص الطويل
- **المصور الصوتي** رسومات طيف وموجات حية قابلة للتخصيص

وهو غير مقتصر على Spotify. يقرأ التطبيق المساعد جلسات وسائط Windows المدعومة ومخرجات الصوت من المتصفحات ومشغلات الوسائط والتطبيقات الأخرى.

## الخصوصية والتخزين المحلي

صُمم NZXT-ESC حول التخزين المحلي للمتصفح:

- تُخزَّن إعدادات الإعدادات المسبقة في **LocalStorage**.
- تُخزَّن الصور والفيديوهات المحلية في **IndexedDB**.
- لا تُرسَل قراءات مستشعرات NZXT CAM ولا الإعدادات المسبقة التي ينشئها المستخدم إلى أنظمة التحليلات.
- لا يجمع التطبيق عمدًا أي معلومات تعريف شخصية.

يستخدم الموقع الإنتاجي **Google Tag Manager** و**Google Analytics 4** لتحليلات منتج مجهولة الهوية اختيارية. تدير **CookieYes** موافقة المستخدم عند الحاجة، وتُفعَّل ملفات تعريف ارتباط Google Analytics وفقًا لخيارات موافقة المستخدم.

يستخدم الموقع المنشور أيضًا **Cloudflare Web Analytics**، المفعّل عبر Cloudflare Pages والعامل بشكل مستقل عن Google Tag Manager. يوفّر هذا تحليلات لحركة الموقع وأدائه تراعي الخصوصية دون استخدام ملفات تعريف الارتباط أو LocalStorage.

## الأسئلة الشائعة

<details>
<summary><strong>هل أحتاج إلى تثبيت NZXT-ESC؟</strong></summary>

لا يتطلب المحرر الأساسي تثبيتًا منفصلًا. افتحه عبر NZXT CAM Web Integration. فقط عناصر التراكب الموسيقية الاختيارية تتطلب عميل NowPlaying.WebSocket المحلي لنظام Windows.

</details>

<details>
<summary><strong>هل يعمل NZXT-ESC دون NZXT CAM؟</strong></summary>

يمكن فتح المحرر في متصفح عادي، ويستخدم قيم مستشعرات تجريبية للتصميم. تتطلب المراقبة الحية للعتاد والعرض على شاشة Kraken وجود NZXT CAM Web Integration.

</details>

<details>
<summary><strong>ما أجهزة NZXT Kraken المدعومة؟</strong></summary>

يدعم NZXT-ESC مبردات **NZXT Kraken Elite، وKraken Plus، وKraken (2023)، وسلسلة Kraken Z** المزوّدة بشاشة LCD والتي توفّر وضع عرض NZXT CAM Web Integration.

راجع القائمة الكاملة في [أجهزة NZXT Kraken LCD المدعومة](#supported-nzxt-kraken-lcd-models).

</details>

<details>
<summary><strong>أين تُخزَّن الإعدادات المسبقة والوسائط المحلية؟</strong></summary>

تُخزَّن الإعدادات المسبقة في LocalStorage الخاص بالمتصفح، بينما تُخزَّن الصور والفيديوهات المحلية في IndexedDB. صدّر إعداداتك المسبقة المهمة بانتظام عند الانتقال إلى متصفح آخر أو تثبيت Windows آخر أو جهاز كمبيوتر آخر.

</details>

<details>
<summary><strong>هل تتطلب ميزة التشغيل الحالي تطبيق Spotify؟</strong></summary>

لا. يستخدم NowPlaying.WebSocket جلسات وسائط Windows المدعومة وصوت النظام، لذا يمكنه العمل مع المتصفحات والتطبيقات الأخرى المتوافقة.

</details>

<details>
<summary><strong>هل يمكن تعديل الإعدادات المسبقة من المجتمع؟</strong></summary>

نعم. الإعدادات المسبقة المستوردة من استكشاف قابلة للتعديل بالكامل بعد إضافتها إلى المكتبة.

</details>

<details>
<summary><strong>كيف يعمل وصول الداعمين؟</strong></summary>

يُطوَّر NZXT-ESC ويُصان بشكل مستقل. وبعد أن تحصل على وقت كافٍ لتجربة المشروع بشكل حقيقي، قد يسألك NZXT-ESC عمّا إذا كنت ترغب في دعم تطويره المستمر أو منح نفسك وقتًا إضافيًا لاتخاذ القرار.

ليس من الضروري أن يكون الدعم ماليًا. فالملاحظات، وتقارير الأخطاء، والأفكار، ومشاركة المشروع، ومساعدة الآخرين على اكتشافه، وغيرها من المساهمات المجتمعية الهادفة، كلها تساعد NZXT-ESC على النمو.

تتوفر رموز وصول الداعمين لداعمي المشروع، ويمكن أيضًا منحها لأعضاء المجتمع الذين يساهمون بشكل ملموس في NZXT-ESC.

يُحتسَب وقت الاستخدام فقط أثناء تشغيل NZXT-ESC فعليًا على شاشة Kraken.

</details>
